# Aster icons

Aster 전용 아이콘의 SVG 원본을 관리하는 디렉토리입니다. 이 디렉토리는 Git으로 관리하며 GitHub에도 포함합니다.

- 파일 이름은 용도 기준 소문자·하이픈으로 정합니다. 같은 용도는 같은 원본을 재사용합니다.
- 새 아이콘은 기존 항목의 형태·크기·색상·선 굵기·텍스트 정렬과 비교합니다. 기준을 판단하기 어려우면 구현 전에 사용자에게 확인합니다.
- 전용 아이콘이 없는 항목은 현재 시스템/기존 아이콘을 유지하고 필요할 때 순차적으로 교체합니다. 기존 아이콘을 한꺼번에 새로 만들지 않습니다.
- 화면에서는 SVG를 import해서 사용합니다. 앱 메뉴는 같은 SVG를 CSS mask로 표시하고 Aster 테마의 글자색을 따릅니다. 별도로 그린 메뉴용 복제본을 만들지 않습니다.
- 앱 메뉴의 아이콘 칸은 16px입니다. 아이콘 없는 항목도 같은 폭의 빈 칸을 유지해 글자 시작선을 맞춥니다.

현재 원본: `copy.svg` — 겹친 문서 형태의 단색 복사 아이콘. SVG 파일을 열어 확인·편집할 수 있습니다.

## 재사용 카탈로그

- 아이콘을 추가할 때 SVG 원본과 `catalog.json` 항목을 함께 추가합니다.
- `node scripts/build-icon-catalog.mjs`로 `docs/design/aster-icons.html`을 생성합니다. 다른 작업 트리의 로컬 문서를 갱신하려면 출력 경로를 첫 인자로 전달합니다.
- HTML은 SVG 원본을 읽어 생성한 비교용 파생물입니다. 직접 편집하지 않습니다. docs는 저장소 정책에 따라 로컬 전용이며, 원본 SVG·목록 JSON·생성 스크립트는 Git 관리 대상입니다.

`trash.svg` — 카탈로그에서 선택해 삭제 메뉴에 적용한 단색 휴지통. 원본은 currentColor이며 앱 메뉴에서 다른 아이콘과 같은 글자색으로 표시합니다.
