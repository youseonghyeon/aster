# Outline 01 — 검토용 시안

Aster 아이콘 비교 시안입니다. `reload.svg`는 승인된 앱 메뉴에서 사용하며 나머지는 검토용 후보입니다. `node scripts/build-icon-catalog.mjs`로 생성한 `docs/design/aster-icons.html`을 브라우저로 열어 비교합니다.

24×24 viewBox, 1.6 stroke, round cap/join, currentColor. SVG가 원본이며 카탈로그 HTML은 원본을 표시하는 비교 자료입니다. 사용자 선택 후 필요한 아이콘만 상위 icons/로 승격합니다. 이름 복사·삭제·최근 문서 후보를 만들었다고 현재 기능/표시 정책을 변경하지 않습니다.
